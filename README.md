# 缓购 · PauseCart

**想清楚，再决定。**

一个面向中文网购场景的 Android 购买前暂停助手：保存商品、设置冷静期，在自选购物 App 中尝试自动提醒，购买与否由你决定。

**v0.1.0-beta.1 · 早期测试版 · Android 8.0+ · 本机存储 · 无账户 / 广告 / 模型 API**

[下载与安装](#下载与安装) · [系统与兼容性](#系统与兼容性) · [权限说明](#权限说明) · [隐私](PRIVACY.md) · [反馈](https://github.com/Aurora-Lucas365/PauseCart/issues)

</div>

> **先看状态：**本项目提供可用的本机冷静清单，以及可选的购物 App 入口提醒和实验性结算识别。结算规则尚未在淘宝、京东、拼多多真实页面验证，可能漏报、误报或完全不可用。不是付款拦截器，不能确保阻止交易。请查看 [兼容记录](docs/COMPATIBILITY.md) 和 [验证记录](docs/VALIDATION.md)。

## 适合谁

- 网购时容易临时起意，希望在下单前给自己一点思考时间的人。
- 愿意先保存商品、稍后自行决定的人；也可以只使用清单，不开任何敏感权限。
- 愿意帮助验证不同安卓手机和购物 App 版本的早期测试者。

不适用于依靠软件确保禁止付款、管理他人手机或诊断 / 治疗消费行为问题的场景。

## 第一版能做什么

| 功能 | 当前状态 |
| --- | --- |
| 手动保存名称、可选价格、链接或口令 | 已实现；所有内容需自己确认 |
| 系统分享文字 / 链接到缓购 | 已实现；购物 App 必须提供相应分享入口 |
| 1 / 24 / 72 小时冷静期、再等 24 小时 | 已实现 |
| 手动记录购买 / 放弃、购买感受、撤销决定 | 已实现；不会自动查询订单 |
| 可选到期通知 | 已实现；默认关闭，系统可能延后送达 |
| 淘宝 / 京东 / 拼多多入口提醒 | 已实现；需要授权，真机兼容性待验证 |
| 三个平台结算页面规则 | **实验**；未真机验证，不承诺覆盖任何具体版本 |
| 放行 15 分钟、暂停自动提醒、删除全部本机数据 | 已实现 |
| 截图识别、AI 教练、跨设备同步、iOS | 未提供 |

清单不是购物车：冷静期不锁商品，也不会自动付款。到期只是可以重新考虑，不是催你购买。商品标价和放弃次数不等于真实节省金额。

已检查 APK 内原生库的 ELF 加载段为 16 KB 对齐；这不是 16 KB 页大小真机运行已验证的声明。

## 下载与安装

1. 打开 [Releases](https://github.com/Aurora-Lucas365/PauseCart/releases)，选择最新的 **Pre-release**。
2. 在 **Assets** 下载 `PauseCart-0.1.0-beta.1.apk`。`Source code.zip` 是源码，不是手机安装包。
3. 在手机打开 APK。如系统询问，只为你使用的浏览器或文件管理器允许安装此来源的应用；安装完成可关闭该来源权限。
4. 打开“缓购 PauseCart”，先体验“记下想买的东西”和演示；基础清单无需无障碍授权。
5. 需要自动提醒时，再按下方说明开启。无需 Root、开发者模式、ADB、Shizuku、购物账号或银行账号。

仅从本仓库下载。Release 同时提供 `SHA256SUMS.txt` 与签名摘要，供核对完整性。GitHub 下载可达性取决于网络，当前无第三方下载镜像。系统可能对外部来源额外检查；不要关闭手机的整体安全防护。若系统阻止某项权限，请先确认来源，再按系统提供的正常路径处理。

### 开启自动提醒

1. 在“提醒设置”给淘宝、京东或拼多多选择 **入口提醒**，先验证基础行为。
2. 点击“查看授权说明 / 打开无障碍设置”，阅读本机处理范围并明确同意。
3. 在系统无障碍设置的已下载服务 / 已安装应用中找到“缓购 · 可选购物提醒”，由你开启。各系统菜单名称不同，荣耀手机可在设置中搜索“无障碍”。
4. 回到缓购检查服务状态；“服务已连接”并不表示结算识别已验证。
5. 如需试用“结算提醒 · 实验”，单独阅读并确认实验提示。同一 App 的入口 / 结算模式二选一。
6. 查订单、售后或计划内购物可临时放行 15 分钟；“暂停自动提醒”可停止处理。

部分 Android 版本对侧载应用的敏感设置有限制。可能需要在应用信息页使用系统提供的“允许受限设置”，具体以手机实际界面为准；没有此入口时请提交兼容反馈。此操作不是所有手机都需要，也不保证解除其他系统限制。

### 权限说明

| 权限 / 系统设置 | 是否必需 | 用途 |
| --- | --- | --- |
| 无障碍服务 | 自动提醒才需要 | 接收界面变化；入口模式不提取页面文本，实验结算模式在所选购物 App 中提取必要节点并本机判断 |
| App 切换事件 | 无障碍服务工作时 | 只用于判断离开目标 App、撤下提醒，不读取非目标 App 的页面内容 |
| 通知 | 仅到期通知需要；Android 13+ 由系统询问 | 发送中性、合并的到期提示，默认关闭 |
| 后台 / 自启动相关设置 | 部分品牌可能需要 | 避免系统冻结服务；不是保证后台永不停止 |
| WorkManager 合并的系统权限 | 由依赖声明 | 后台任务使用的唤醒锁、开机恢复、网络状态 / 前台服务基础声明等，具体以安装包清单为准；应用没有网络请求功能 |
| 互联网、录屏、读通知、通讯录、短信、位置、银行账号 | 不需要 | 本版没有这些功能 |
| 单独的普通悬浮窗权限 | 不需要 | 自动提醒使用系统的无障碍覆盖窗口，不提供常驻悬浮球 |

界面不用一直打开；自动提醒依赖无障碍服务连接。强行停止、撤销权限、系统升级、省电管理、锁屏或重启后的恢复情况都需要在实际设备验证。无需为了基础清单长期开放敏感权限。

## 它如何判断结算

```text
界面事件 → 确认是所选购物 App → 检查模式和临时放行
    ├─ 入口模式：进入时显示一次暂停提醒
    └─ 实验结算模式：本机组合判断页面标题 + 操作按钮 + 排除条件
             → 高置信规则命中才提醒；价格不可靠就不填写
```

只根据系统正常提供的界面判断，不接入支付系统、不监听加密交易、不修改购物 App、不注入代码、不自动点击。到支付宝、微信、系统界面或其他 App 后撤下覆盖提醒。规则可能受到页面改版、语言、促销、WebView、自绘控件和安全保护影响。

“继续购物”只关闭提醒，不会替你点击原页面。付款决定与操作由你完成。关闭面板后请重新核对商品、规格和金额。

## 数据与隐私

无账户、无广告、无分析 SDK、无云端同步、无模型服务；应用不声明 `INTERNET` 权限。数据库仅在本机，系统自动备份关闭。界面文本只在内存中短暂处理，不保存完整结算页面、不写原始页面日志。手动保存的名称 / 价格 / 链接与决定由你控制。

可删除单条记录，或在“说明”删除全部数据并停用提醒。卸载会删除应用本机数据，当前无导出功能，卸载前自行保留需要的信息。完整说明见 [PRIVACY.md](PRIVACY.md)。

## 常见问题

<details><summary>为什么不是兼容所有 Android 版本？</summary>

Android 8.0 是本版安装下限。系统、厂商后台管理和购物 App 页面各自变化，不能承诺所有组合。项目公开“已验证 / 待验证 / 不支持”，不会把授权成功当作付款识别成功。
</details>

<details><summary>为什么没有提醒，或提醒出现得不对？</summary>

检查是否启用对应平台、是否暂停或临时放行、服务是否连接。实验模式可能读不到页面或规则不适配；改用入口模式并提交型号 / 系统 / App 版本与操作步骤。不要提交完整结算截图、地址、订单号、付款码等信息。
</details>

<details><summary>会一直截图、一直耗电吗？</summary>

本版不截图、不录屏。无障碍按事件触发，非目标 App 不提取页面文本，实验规则有限频。真实耗电尚未完成多机测试，不能承诺具体百分比。
</details>

<details><summary>GitHub Release 需要吗？以后会收费吗？</summary>

Release 是下载入口，不是使用 App 的前提。提供签名 APK、校验值、版本说明比只放源码方便。此测试版无收费功能；暂无应用商店版本，不能将 GitHub 发布理解为商店审核通过。
</details>

## 构建与开发

JDK 17、Android SDK Platform 35 / Build Tools 35.0.0，Gradle Wrapper 8.9。

```bash
./gradlew testDebugUnitTest lintDebug assembleDebug
./gradlew connectedDebugAndroidTest  # 需要测试设备或模拟器
```

Windows 使用 `gradlew.bat`。`local.properties` 中配置本机 `sdk.dir`，不要提交。Release 签名读取 `PAUSECART_KEYSTORE`、`PAUSECART_STORE_PASSWORD`、`PAUSECART_KEY_PASSWORD`，别名为 `pausecart`；不设置时只能构建未签名 release，不能直接安装它。

```text
app/src/main/.../core      纯规则、金额校验、分享解析、限频
app/src/main/.../data      Room 本地数据、偏好、可选到期通知
app/src/main/.../service   系统事件与无障碍覆盖提醒
app/src/main/.../MainActivity.kt  Compose 界面
docs/                     兼容、验证与发布记录
```
