# 缓购 · PauseCart

**买之前，停一下。**

打开购物 App 时给自己一个提醒，把想买的东西先记下来，过一阵再决定。

[下载安装](https://github.com/Aurora-Lucas365/PauseCart/releases) · [使用帮助](docs/GUIDE.md) · [反馈问题](https://github.com/Aurora-Lucas365/PauseCart/issues)

Android 8.0+ · 本机存储 · 无账号、广告和互联网权限

> **版本状态：**0.2.0-beta.1 正在改版验证。当前公开的 0.1.0-beta.1 已收到荣耀 400 上入口不提醒、模式选项更新慢的反馈，请勿把旧包当作修复版。新版安装包和验证结果准备好后会更新本页。

## 可以做什么

- **购物提醒**：为淘宝、京东、拼多多分别选择打开时提醒；下单前提醒收在进阶试用中。
- **冷静清单**：手动记录或分享导入，等待 1 / 24 / 72 小时，再记录买了、不买了或继续等。
- **少一点打扰**：同一次访问只提醒一次；主动放行 15 分钟，可随时结束。

自动提醒帮助你停下来想一想，购买决定始终由你完成。

## 安装与权限

1. 在 [Releases](https://github.com/Aurora-Lucas365/PauseCart/releases) 的 **Assets** 下载 `.apk`，在安卓手机打开安装。源码压缩包不能直接安装。
2. 需要自动提醒时，在提醒页选择购物 App，并按引导开启 **无障碍服务**。荣耀若提示“受限制的设置”，到应用信息页寻找系统提供的解除入口，再回来开启。
3. 返回桌面，打开购物 App；未出现提醒时，进入缓购的 **没有出现提醒？**，逐步检查。通知仅在你选择到期通知时需要。

基础清单不需要无障碍权限。无需 Root、开发者模式、Shizuku、录屏或普通悬浮窗权限。使用同一签名的新 APK 可覆盖升级，建议保留原有清单，不要先卸载。

| 项目 | 说明 |
| --- | --- |
| 系统 | Android 8.0 及以上；不支持 iPhone |
| 安装包 | ARM64、ARMv7、x86、x86_64；不依赖 Google 服务 |
| 购物 App | 淘宝、京东、拼多多的标准版；极速版、分身与工作资料需单独适配 |
| 荣耀 400 / MagicOS 10 / Android 16 | 旧版已报告问题；新版待手机复测 |
| 下单前提醒 | 试用功能；页面改版、敏感界面和系统保护可能造成漏报 |
