# 测试与兼容反馈

## 自动检查

- JVM：访问内去重、离开 30 秒的新访问、平台独立放行、模式变更重置、保守结算判断、金额与分享解析。
- UI：连续切换 20 次并立即核对开关、默认冷静期、保存价格、清单与购买决定。
- 服务：本机 debug 模拟页面触发真实无障碍窗口；检查入口、结算规则、切换关闭、暂停 / 恢复、放行 / 结束放行。
- 安装包：没有互联网权限，备份关闭，不可调试，debug 页面不进入正式安装包。

运行环境与通过结果见 [验证记录](VALIDATION.md)。本机模拟页面没有商家、账号或交易，不能替代真实三平台验证。

## 手机验证顺序

先清单与设置，再打开时提醒，最后按需试用下单前提醒。无需付款。

| 场景 | 核对内容 |
| --- | --- |
| 不授权 | 清单仍可新增、重开读取和删除 |
| 快速切换开关 / 提醒时机 | 选择立即更新，旧任务取消 |
| 进入所选 App | 未暂停、未放行时出现入口卡 |
| 短暂切换与离开 30 秒 | 同次访问不重复，新访问重新提醒 |
| 继续逛逛与结束放行 | 只按目标平台放行，剩余时间可见，结束后恢复 |
| 暂停 / 关闭 | 撤下窗口并停止处理；恢复后重新核对 |
| 系统设置、其他 App、锁屏 | 不残留提醒窗口 |
| 结算试用 | 观察确认订单页；历史订单、退款、支付结果不应提醒 |
| 后台、省电、重启、分身 | 查看诊断，不预设恢复或兼容成功 |
| 大字体、横屏、键盘、小屏幕 | 按钮可达、表单可滚动、关闭正常 |
| 覆盖升级 | 签名一致、版本更高，原清单保留 |

请反馈手机、系统、Android 版本、缓购版本、购物 App 版本、提醒时机、操作步骤与检查结果。不要上传地址、订单号、密码或支付码。
