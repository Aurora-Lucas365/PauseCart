## 测试实际覆盖

- 规则：同次访问去重、离开 30 秒后新访问、平台独立放行、模式变更重置、保守结算判断、金额精度和分享解析。
- 每个模拟器 2 项 UI 流程：连续切换 20 次并核对开关、默认时间选择；保存价格、查看清单、记录决定。
- 每个模拟器 2 项服务流程：本机 debug 页面触发真实无障碍窗口，核对入口、结算组合规则、切换模式、暂停 / 恢复和主动放行 / 结束放行。
- debug 模拟页与设置页共用包名，debug 构建通过本机页面标记区分二者，不依赖系统是否报告 Activity 类名；正式版通过购物 App 各自包名识别。该受控测试不能替代真实购物 App 的进入事件验证。
- 测试结束恢复模拟器的无障碍设置，不访问商家、不执行交易。测试页不进入正式安装包。
