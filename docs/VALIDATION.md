日期：2026-10-19。生产代码、自动测试与签名安装包均对应提交 `4ad4ec9f9fb532bd2ce32c2cfdac5b971fe4c1a7`。后续文档提交不改变生产代码。

## 用户反馈与本次改动

荣耀 400 / MagicOS 10 / Android 16 用户确认 beta.1 无障碍已连接，窗口自检可以显示，入口偶发等待约 3～5 秒；这证明入口有时能够触发，但没有测得系统事件何时到达。真实下单前提醒仍未验证成功。

代码检查发现 beta.1 在大量内容事件中同步读取当前窗口根节点，且切换期间窗口过时可能使检测等待后续事件。beta.2 优先用事件包名与前台窗口 ID 核对，并有限次重试；这是针对已知代码路径的修正，尚不能认定已消除荣耀手机全部延迟。

## 流程实际覆盖

每个模拟器：2 项清单 / 设置流程，2 项同包名服务流程，2 项跨包名服务流程。

跨包名测试使用单独的 androidTest APK，在测试构建中加入该测试包识别，不冒充购物 App。检查进入后无需滑动即可显示、返回缓购后撤下，以及模拟确认订单页面触发。入口测试断言从服务收到目标事件到添加窗口少于 2 秒；未测量真实商家完整启动延迟，也未在荣耀手机实测。

规则增加对无可读文字、缺少标题、缺少按钮、保护性排除的判断与说明。未扩宽真实商家的识别规则；诊断不保存原始页面文字。

旧的同包名 debug 页面仍由本机标记区分，其结果仅用于受控服务流程。正式 APK 不识别测试包，也不包含测试 Activity。

## 待验证与发布状态

beta.2 仍待荣耀手机复测入口速度、三平台真实页面、品牌后台恢复、ARM 真机、长期耗电与完整启动延迟。16 KB 页大小为静态检查，未做该页大小真机验证。

下单前提醒已实现，但尚未完成真实三平台结算适配，保留试用标识，不保证可用。建议先使用打开时提醒；切换到下单前模式后，首页打开本身不应触发提醒。

Release 保持草稿，不把模拟器受控页面成功说成真实购物平台已适配。
