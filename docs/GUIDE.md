# 使用帮助

## 首次使用

Android 8.0+；在 Release 的 Assets 下载 APK。系统若询问，仅对用于安装的浏览器或文件管理器允许该来源安装。安装后可关闭这个来源权限。系统最终的安全检查与权限确认由你操作。

基础清单无需授权。在“清单”手动新增，或从购物 App 的系统分享菜单选择缓购；没有分享入口时，复制后自己粘贴到新增表单。

## 开启自动提醒

在“提醒”选择淘宝、京东或拼多多。点击“去开启”，阅读处理范围并同意，再在系统无障碍设置启用“缓购 · 购物提醒”。返回缓购确认连接。

荣耀 / MagicOS 若显示“受限制的设置”：设置 → 应用 → 应用管理 → 缓购 PauseCart，在应用信息的更多菜单中寻找“允许受限制的设置 / 解除限制”。名称、位置与可用性随系统变化。再返回无障碍页面开启。找不到入口时请反馈实际界面，不必为了清单开启敏感权限。

## 为什么没有提醒

“没有出现提醒？”分开显示系统授权、服务连接、窗口检查和最近购物 App 检测。

- 开关已开但服务未连接：返回系统确认权限，必要时关闭再开启该无障碍服务。
- 窗口检查失败：查看页面给出的失败原因，反馈应用版本、型号与系统。
- 窗口检查成功但没有购物 App 记录：确认标准版已安装，检查分身、工作资料和后台冻结。
- 已检测到但未提醒：检查暂停、临时放行、同一次访问去重，以及下单前试用规则是否命中。

预览提醒只演示界面；本机窗口检查也不证明真实购物平台检测已通过。无需为了测试进行付款。

## 下单前提醒为什么标为试用

此模式已包含识别逻辑，需在“设置 → 进阶：提醒时机”按平台选择；它与打开时提醒为二选一。不是打开 App 就弹出。

它需要在所选购物 App 内同时读取到确认订单标题和提交 / 支付按钮。实际页面可能改版、使用不可读取的控件或受系统保护，当前没有完成三平台真实结算验证，不能保证每次出现。请先使用打开时提醒。

beta.2 检查页会说明未触发的原因：无可读文字、缺少订单标题、缺少提交按钮、支付或历史页面被排除。不为测试而付款，无需提供页面原始内容。

## 提醒慢怎么检查

beta.1 荣耀用户报告入口偶发 3～5 秒；beta.2 优化事件与窗口核对，尚待该手机复测。“最近显示耗时”仅从缓购收到事件开始计时，不包含 App 启动或系统派发事件之前的时间。

分别记录体感延迟与检查页耗时；两者差距大时需要继续定位系统事件到达时间。不要把同次访问的 30 秒离开规则或主动放行当成弹窗延迟。

## 提醒与放行

同一平台的同一次访问只提醒一次。离开该平台满 30 秒后再进入，开始新一次访问；短暂切换不重复打扰。

只有主动选择“继续逛逛 · 15 分钟不提醒”，才开启该平台的 15 分钟放行。提醒页显示剩余时间，可随时结束。模式更改会清理旧任务、旧去重状态与该平台的放行。

暂停立即停止自动提醒并撤下窗口；锁屏、离开目标平台或服务断开会撤下窗口。系统可能冻结或停止服务，不能保证后台永不停止。界面无需一直打开。

## 权限

| 设置 | 用途 |
| --- | --- |
| 无障碍 | 自动提醒才需要。入口模式只判断包名、窗口等元数据；下单前试用只在所选平台短暂提取必要文字，本机判断 |
| 通知 | 冷静期到期通知才需要；Android 13+ 单独询问，默认关闭 |
| 后台 / 自启动 | 部分系统可能需要人工调整，具体以实际手机为准 |

不需要互联网、Root、开发者模式、ADB、Shizuku、录屏、读通知、通讯录、短信、位置或普通悬浮窗。WorkManager 依赖会合并后台任务所需的系统声明，详见安装包清单。

## 清单、升级与数据

价格、购买决定和感受由你确认。放弃商品标价不等于真实节省金额。冷静期到期只是可以重新考虑，不会催促或自动购买。

同包名、同正式签名的 APK 可覆盖安装。不要为了升级先卸载：卸载会删除本机数据，当前没有导出或云端恢复。可删除单条记录，或在设置中删除全部数据。

## 兼容反馈

请提供缓购版本、手机型号、Android / 系统版本、购物 App 名称及版本、提醒模式、复现步骤和检查结果。不要公开订单、地址、密码、支付码或完整结算截图。
