# 缓购 PauseCart 0.1.0-beta.1

首个 Android 早期测试版。想清楚，再决定。

## 下载

在本页 Assets 下载 **PauseCart-0.1.0-beta.1.apk**。Source code 压缩包是源码，不是安装包。校验文件为 SHA256SUMS.txt，签名摘要为 SIGNATURE.txt。

## 功能

- 本机冷静清单、文字 / 链接分享导入、1 / 24 / 72 小时等待、延长等待。
- 自报购买 / 放弃、购买感受、撤销决定。
- 可选到期通知，默认关闭。
- 可选淘宝 / 京东 / 拼多多入口提醒、实验性结算规则、15 分钟放行与暂停。

## 安装与授权

Android 8.0+；安装包含 ARM64 / ARMv7 / x86 / x86_64 四种 ABI，不依赖 Google 服务。下载后打开 APK，按系统允许相应来源安装。先体验清单，再在“提醒设置”阅读说明并按需开启系统无障碍服务。到期通知单独选择。

无需 Root、开发者模式、ADB、Shizuku、录屏、普通悬浮窗或银行账号。无互联网权限。数据仅在本机，卸载会删除数据，当前没有导出功能。

## 必须了解的边界

- 荣耀 400 / MagicOS 10 / Android 16 是待测试配置，不是已经实测通过。
- 真实淘宝、京东、拼多多版本与结算路径尚未验证，实验规则可能漏报、误报或完全不可用。
- 本软件不能保证阻止付款；系统保护页面不绕过。购买操作始终由用户自己完成。
- 自动提醒依赖服务连接与后台运行，Android 17 高级保护等配置可能限制它。
- 不支持 iOS。
